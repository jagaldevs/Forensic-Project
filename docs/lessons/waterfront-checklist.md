# The Waterfront Alibi: checklist

Name: ______________________________ Date: ____________

**Stuck? Ask yourself: What does this show? What does it _not_ show? What else would help?**

### 1. Read the briefing

- [ ] What claim do people think "settles it"? ____________________________________________
- [ ] When did the trophy go missing? ______________ to ______________

### 2. Login record (Evidence Locker)

- [ ] What time was the login, and from which IP address?
- [ ] Does it say **who** logged in, or **where** they were?
- [ ] Pin it to the board.

### 3. IP Lookup (type `203.0.113.47`, then press **Look up**)

- [ ] How big is the accuracy radius?
- [ ] Look at the circle on the map. Which places are inside it?
- [ ] Pin it. _New evidence may arrive soon._

### 4. Network Log (needs a warrant)

- [ ] You only have two warrants. Ask only for what you need. _A refused request doesn't use
      one up._
- [ ] Whose internet connection is `203.0.113.47`?
- [ ] Which devices were online at 7:52 pm? A device is not a person.
- [ ] Pin it.

### 5. Photos (open Photo A, then Photo B when it arrives, and press **Get info** on each)

- [ ] When and **where** was each one taken?
- [ ] Can you tell **who** is in it?
- [ ] Pin both.

### 6. Judgements: questions 1 to 3

- [ ] Choose a verdict and attach the evidence that matters (not everything does).
- [ ] Write: "It shows … but it doesn't show …"
- [ ] Add one limitation, press **Check**, read the hint, and try again.

| Verdict                | Means                           |
| ---------------------- | ------------------------------- |
| **Strongly supported** | The evidence clearly shows it   |
| **Possible**           | Fits, but doesn't prove it      |
| **Not supported**      | Points the other way            |
| **Can't tell**         | Can't confirm it or rule it out |

### 7. Question 4: what next?

- [ ] Name two more pieces of evidence that would help, and what each could show.
- [ ] Which one needs a warrant, and why is that request fair?

### 8. Report

- [ ] Open it, fill in the self-check, and hand it in.
